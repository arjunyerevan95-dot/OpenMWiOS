## Established cause and constraints

Fast run `33265712820` passed patch bootstrap and source validation, then failed during cold OSG CMake configuration. A missed incremental build-state cache exposed optional host GLib discovery. Pinned OSG's non-required `FIND_PACKAGE(GLIB COMPONENTS gobject)` resolved `/usr/local/Cellar/glib/2.88.2`, and `FindGLIB.cmake` attempted to read an absent `glibconfig.h`.

Direct source inspection establishes:

- pinned OSG documents and supports `CMAKE_DISABLE_FIND_PACKAGE_<Package>`;
- the iOS build does not currently disable optional GLib discovery;
- the required static iOS OSG plugin set is BMP, DDS, FreeType, JPEG, PNG, OSG serializers, and TGA; and
- no required iOS plugin in that set depends on GLib.

The authorized recovery candidate is therefore the iOS-only OSG configuration argument:

`-DCMAKE_DISABLE_FIND_PACKAGE_GLIB=ON`

An equally narrow spelling/location is allowed only if direct inspection proves the same CMake effect. Do not install/upgrade Homebrew GLib, hard-code a host path, change dependency revisions, delete caches, manipulate cache keys, or disable unrelated optional packages.

The reviewed WO37 diagnostic candidate preserves valid explicit target requests and otherwise auto-arms the same bounded, one-shot capture at first eligible exterior fog generation. It is observer-only and remains unaccepted until a qualified IPA and device run validate it.
