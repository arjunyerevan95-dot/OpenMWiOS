## Final orchestrator disposition

**ACCEPT.** The first invalid boundary is proven: on the Apple/manual GL4ES route, OSG's valid cache can report `GL_BLEND` already enabled while the GL4ES state used by the draw remains disabled, causing OSG to suppress the reconciliation call.

Correction `93f892dd0cf9834259b4cad2045ddb2ef9c53ed9` narrowly reasserts only a cache-matching `GL_BLEND` request through GL4ES under Apple + `OPENMW_GL4ES_MANUAL_INIT`, preserves OSG's cache-match return semantics, and leaves GL4ES's existing comparison authoritative. It does not force blend at draw time or change factors, depth, shaders, textures, render-list behavior, foliage code, distance/horizon code, touch, dependencies, or workflow behavior.

Fast run `32771773194` built that exact commit successfully. The correction trace contains four representative smoke target records at `blend=1` and none at `blend=0`. Device evidence visibly qualifies chimney smoke and spell blending; foliage transparency also visibly improved without a dedicated foliage-target causal trace. No crash or obvious HUD/landscape/exterior-traversal regression was reported.

The accepted engineering baseline advances to `93f892dd0cf9834259b4cad2045ddb2ef9c53ed9`. Distance/horizon rendering remains unresolved and untouched. Full Qualification did not run.

See [DEC-013](../Decisions/DEC-013.md) and the [final orchestrator review](../Evidence/WO-033/orchestrator-final-review.md).

## Established facts

- The exact WO32 correction source compiled and ran; stale/wrong-source IPA is excluded.
- `textures/tx_smokealpha00a.dds` reaches program 9 as a translucent DXT5 target with standard alpha factors, disabled depth writes, and fragment discard/alpha output.
- Four corrected-candidate draws still record `blend=0`; visible smoke remains blocky.
- GL4ES `gl4es_glEnable` and `gl4es_glDisable` call `proxy_glEnable`; its `GL_BLEND` case mutates `glstate->enable.blend` when the requested value differs.
- The target draw diagnostic reads `glstate->enable.blend` in `glDrawElementsCommon` on the actual draw path.
- GL4ES can batch/intercept work through render lists before common draw execution.
- Source and patch presence do not prove that a conditional branch was compiled or exercised for the target draw.
