# DEC-003 — Resolve Default Game Data from the Current iOS Documents Directory

Status: established

## Decision / finding

The default Morrowind data path is a runtime relationship to the current application Documents directory: `OpenMW/Morrowind/Data Files`. A persisted `/var/mobile/Containers/Data/Application/<UUID>/...` prefix is not a stable configuration identity and must not be required.

The implemented integration supplies the runtime-resolved base path and narrowly handles recognized legacy generated UUID entries while preserving unrelated user/mod configuration.

## Why it matters

iOS may replace the application-container UUID across installation lifecycle events. Runtime directory resolution eliminates routine manual `openmw.cfg` repair and removes worker/tool knowledge of the UUID from the default flow.

## Evidence

- Correction commit `6db1c2af5066f810df97c5af39bdbf2a48fb86b5`.
- Fifteen focused regression tests, including simulated container A/B resolution and config preservation.
- Fast Development run `32480504839` (success).
- [WO-027](../WorkOrders/WO-027.md) accepted device launch without a manual config edit or externally supplied UUID/path.
- [WO27 evidence manifest](../Evidence/WO-027/manifest.md).

## Applies to

- Default game-data discovery under the application Documents tree.
- Migration of the known platform-generated legacy default entry.

## Does NOT establish

- That the container UUID changed during the accepted physical install; the post-install UUID was not recorded.
- A user-facing Files folder picker.
- Security-scoped bookmark support for external/provider folders.
- Permission to rewrite arbitrary absolute user or mod paths.

## Supersedes

The development workflow that discovered a current UUID and manually rewrote `openmw.cfg` before each affected launch.
