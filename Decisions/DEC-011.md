## Decision

Accept WO32 Amendment 1 as a partial diagnostic result. Accept the causal localization of the chimney-smoke/particle defect to split OSG/native-GLES versus GL4ES state ownership. Do not accept correction commit `1625713b949ddb0cde5471feead75f29fedadfaa` into the qualified runtime baseline because its only CI run ended before OpenMW compilation and produced no artifact.

Issue WO32 Amendment 2 as READY. It may make one narrowly bounded Fast-workflow timeout change and one replacement correction build so the already-prepared correction can be compiled and device-qualified. It may not alter the renderer correction, resume broad diagnostics, or infer that the correction fixes foliage or distance/horizon rendering.

The accepted engineering baseline remains `195f3a4bbcfd17ecd46546f3e28d3ee8558bed27`.

## Accepted R1 finding

The targeted device capture establishes all of the following for `textures/tx_smokealpha00a.dds`:

- it is a translucent DXT5 asset;
- its applied shader writes alpha and contains discard;
- its intended factors are `SRC_ALPHA` / `ONE_MINUS_SRC_ALPHA`;
- depth writes are disabled;
- the GL4ES-applied draw nevertheless records blending disabled.

Pinned OSG performs the relevant core `glEnable`, `glDisable`, and ordinary `glBlendFunc` calls directly. The diagnostic executable defines the GL4ES wrappers but imports the unprefixed core symbols from native GLES. OSG therefore mutates native GLES state while GL4ES owns program conversion and draw submission. This is the earliest proven smoke/particle boundary.

## Correction status

Correction commit `1625713b949ddb0cde5471feead75f29fedadfaa` changes the deterministic OSG patch so only Apple manual-init builds route the two core mode sites and ordinary blend-function application through GL4ES. Direct source review confirms that other platforms retain the existing direct GL calls. The only additional change is a focused regression assertion.

The correction is a valid source candidate, not an accepted product correction. Fast run `32634038454` passed bootstrap and ordered patch application, then was cancelled at the two-hour job limit during dependency preparation. Compile, link, package, upload, and device validation were skipped; no artifact exists.
